# Job Application Tracker

A React project for tracking job and internship applications.

## Status

Work in progress

I am currently building this project while learning React.

## Current Features

- Application form
- Company name
- Position
- Application status
- Application date
- Basic application statistics

## Planned Features

- Add and save applications
- Display applications in a list
- Update application status
- Delete applications
- Filter applications by status
- Improve the UI

## Built With

- React
- JavaScript
- Vite
- CSS

## About This Project

I created this project to practice React and learn how to build a real application step by step.
